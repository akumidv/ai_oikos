# ACME Corp — the oikos installation

@oikos/OIKOS.md
@.local/AGENTS.md

This folder is the oikos installation of **ACME Corp**. oikos itself is `oikos/` (the core
checkout, read-only here). The organization: `oikos.yaml` (connectors, settings, MCP servers),
`resources/` (one note per resource), `LANDSCAPE.md` (the way in and sign-in). What belongs to this
machine and person is `.local/` (git-ignored); `.local/AGENTS.md` names the paths.

## Knowledge base

The `knowledge` MCP server (`mcp_servers` in `oikos.yaml`); queries in English.

## Sign-in

Web resources sign in through the organization's SSO.
